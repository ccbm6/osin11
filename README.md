# Recon (تطبيق شخصي)
1. أنشئ مستودع GitHub **خاصاً (Private)** وارفع محتوى هذا المجلد.
2. تبويب Actions ← Build APK ← Run workflow (أو يبدأ تلقائياً عند push).
3. حمّل `recon-apk` من Artifacts وثبّت `app-debug.apk` (فعّل التثبيت من مصادر غير معروفة).
4. من ⚙ أدخل مفاتيح Shodan / Hunter / VirusTotal (اختيارية).
